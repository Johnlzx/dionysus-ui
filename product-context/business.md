# Dionysus UI product context

## Product

Dionysus UI is a React design system for high-density creative tools. It gives product teams reusable interface components, semantic themes, and interaction patterns for building calm, information-rich workspaces.

## Users

- Product engineers who build React applications with the shared component package.
- Designers and product teams who use the documentation site to review supported patterns.

## Business modules

- Component Library — reusable controls, navigation, dialogs, surfaces, editing, and agent interaction components.
- Theming — semantic light and dark tokens and theme controls.
- Documentation — discoverability, examples, usage guidance, and component API references.
- Distribution — future package, registry, and starter delivery for product teams.

## Changes that matter

- A new reusable component or interaction capability becomes available.
- An existing component changes visible behavior, supported states, accessibility, or public API.
- Theme behavior or semantic tokens change how consuming products appear or operate.
- Documentation exposes, removes, or materially changes a supported product pattern.
- Distribution availability or integration workflow changes for consuming teams.

## Technical exclusions

- Formatting, generated output, lockfile-only updates, CI maintenance, and internal refactors with no observable behavior change.
- Build optimizations that do not change the component APIs or visible experience.
